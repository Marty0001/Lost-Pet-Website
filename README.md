<h2>A website where users can uplaod posts of their lost pets and increase the chances of finding them.</h2>

<b>Features include:</b>
<ul>
  <li>Likes</li>
  <li>Comments</li>
  <li>Post editing/deleting</li>
  <li>Post sorting/filtering</li>
  <li>Registration/login page</li>
  <li>Image enlargement</li>
</ul>

---

<h3>This is a full stack project using React + Axios + JavaScript for the front end, and PHP + MySQL database for the backend.</h3>

<b>To run locally on your machine:</b>

- Install node.js.

- In the terminal while in the client directory, use 'npm install' to install the dependencies for React.

- Use a tool like XAMPP or Docker to setup a local server enviroment. 

- Import the lost_pet_website.sql file into your database and configire 'db.php' in the server folder to connect to the database.
